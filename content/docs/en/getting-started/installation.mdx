## Requirements

- Linux or macOS. On Windows, use WSL2 (see [Windows](#windows)).
- `git`, `curl` and `openssl`.
- Docker with Compose v2 (`docker compose`). On Linux, the installer offers to install Docker for you. On macOS, install [Docker Desktop](https://www.docker.com/products/docker-desktop/) or [OrbStack](https://orbstack.dev) and start it first.

## Install

Run the installer:

```bash
curl -fsSL https://raw.githubusercontent.com/tabomgui/lifegui/main/install.sh | bash
```

The installer asks for the URL you will use to open lifegui. The default is `http://localhost:8080`. If the host is not `localhost`, it also asks for the local port of the web container. Point your proxy or tunnel at that port.

When it finishes, open the URL it prints and create your account. See [First launch](/docs/getting-started/first-launch).

<Callout type="warn">
  Create your account right away. Until the first account exists, anyone who can reach the URL can claim the instance. Finish setup before you expose lifegui publicly.
</Callout>

## Non-interactive install

Set `LIFEGUI_URL` to skip all questions:

```bash
curl -fsSL https://raw.githubusercontent.com/tabomgui/lifegui/main/install.sh \
  | LIFEGUI_URL=https://life.example.com LIFEGUI_PORT=8080 bash
```

| Variable | Default | Description |
| --- | --- | --- |
| `LIFEGUI_URL` | asked, `http://localhost:8080` | Public URL, in the form `http(s)://host[:port]` without a path. Setting it skips all questions. |
| `LIFEGUI_PORT` | the URL port on localhost, otherwise `8080` | Host port published by the web container. |
| `LIFEGUI_DIR` | `~/lifegui` | Installation directory. |
| `LIFEGUI_REF` | `main` | Branch or tag to install. |

If you use an `https://` URL, the web container still serves plain HTTP. Terminate TLS in a proxy in front of it. See [HTTPS and reverse proxy](/docs/getting-started/https).

## Windows

1. Install [WSL2](https://learn.microsoft.com/windows/wsl/install).
2. Install Docker Desktop with the WSL2 backend.
3. Run the installer in your WSL2 terminal.

## What the installer does

<Steps>
<Step>

### Check prerequisites

It checks for `git`, `curl`, `openssl` and Docker with Compose v2. On Linux, it offers to install Docker with `get.docker.com`. If your user is not in the `docker` group, it uses `sudo` for that run.

</Step>
<Step>

### Get the code

It clones the repository into `~/lifegui` (or `LIFEGUI_DIR`), or updates it if it is already there.

</Step>
<Step>

### Write the configuration

It writes `.env` and `backend/.env` with a random database password and app key. It never overwrites existing files.

</Step>
<Step>

### Build and start

It builds the images locally and starts MySQL, the Laravel API and the nginx web server with Docker Compose. The first build takes a few minutes.

</Step>
<Step>

### Wait for the app

It waits up to 180 seconds for the app to answer, then prints the URL and a few useful commands.

</Step>
</Steps>

## Useful commands

Run these in the installation directory:

```bash
docker compose -f docker-compose.prod.yml logs -f    # follow logs
docker compose -f docker-compose.prod.yml ps         # container status
docker compose -f docker-compose.prod.yml down       # stop lifegui
```

If the app does not answer in time, check the backend logs:

```bash
cd ~/lifegui && docker compose -f docker-compose.prod.yml logs -f backend
```
